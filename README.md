# 片單收藏室

個人電影、影集、動畫的無雷心得網站，使用純 HTML、CSS、JavaScript 製作，透過 GitHub Pages 發布。

## 網站內容
- **首頁**：所有作品的海報牆，可依形式（電影、影集、動畫）與心情標籤篩選
- **心得頁**：每部作品固定包含簡介、無雷心得、推薦對象、個人評分（5 顆星，可加哭點指數）
- **關於**：評分與哭點指數的標準說明

## 給 AI 的規則
專案規則、檔案結構、新增作品流程都寫在 [AGENTS.md](AGENTS.md)。請 AI 協助新增或修改內容前，先讓它閱讀這份文件。

## 新增一部作品
1. 海報改名為 `作品代號.jpg` 放進 `assets/posters/`
2. 複製 `reviews/_template.html` 成 `reviews/作品代號.html` 並填入內容
3. 在 `data/films.js` 最前面加一筆作品資料
